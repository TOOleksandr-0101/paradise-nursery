# Paradise Nursery Submission Checklist

After pushing this project to your GitHub repository, submit these file URLs:

1. `README.md`
2. `src/components/AboutUs.jsx`
3. `src/App.css`
4. `src/App.jsx`
5. `src/store/CartSlice.jsx`
6. `src/components/ProductList.jsx`
7. `src/components/CartItem.jsx`

## URL template

Use this format for each answer:

```text
https://github.com/USERNAME/REPOSITORY/blob/BRANCH/PATH/TO/FILE
```

